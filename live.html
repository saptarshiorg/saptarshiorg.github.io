📎 How to use an IMDB/TMDB ID
  1. Search the title on IMDb or TMDB.
  2. Copy the ID from its page URL — IMDb looks like tt1234567, TMDB is just numbers like 27205.
  3. Paste it into the search box above.
  4. A ▶ Play ID button appears — tap it to play instantly, even if the title isn't in the list below.
