How to install

Android

  1. Download the APK on your phone.
  2. Open the file from Downloads.
  3. If asked, allow installs from this source.
  4. Tap Install, then open EV STREAMS.

Windows

  1. Download the Windows app.
  2. Double-click it to open and set it up.
  3. If SmartScreen appears, choose More info, then Run anyway.
  4. Finish setup and launch EV STREAMS.

Prefer no install?
